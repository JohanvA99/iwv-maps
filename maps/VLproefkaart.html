Publish to GitHub

🐙 GitHub publishing information:
1. Register for a GitHub account.
2. Go to https://github.com/settings/tokens.
3. Click Generate new token and select Generate new token (classic).
4. Verify the security code which you receive in your mail.
5. Enter a Note and set Expiration (which might be 7/30/60/90 days, custom, or no expiration). Note: If the time period ends, you must repeat the entire process again.
6. Select the repo checkbox.
7. Click Generate token at the bottom, copy it, and paste it into the field below.
• This token is valid until your selected time in the step above. Once the time period ends, repeat the process again and paste your new token here in the publish GitHub token input field.
